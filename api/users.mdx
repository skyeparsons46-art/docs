The Users endpoints let you look up public profile information for Story accounts. You can fetch a user's display name, bio, follower count, and published story statistics — useful for building author pages, reader discovery features, or social integrations. You can identify users by their numeric ID or by their `@username`.

<Note>
  The Users endpoints return **public data only**. Accessing your own private profile data — including private or unlisted stories — requires authentication and is available through the authenticated Stories and Chapters endpoints.
</Note>

---

## The user object

Every endpoint that returns a user uses the following object shape.

<ResponseField name="id" type="string">
  The unique identifier for the user.
</ResponseField>

<ResponseField name="username" type="string">
  The user's unique @username on Story.
</ResponseField>

<ResponseField name="display_name" type="string">
  The user's chosen display name.
</ResponseField>

<ResponseField name="bio" type="string">
  The user's public profile bio, or `null` if not set.
</ResponseField>

<ResponseField name="profile_photo_url" type="string">
  The URL of the user's profile photo, or `null` if they haven't set one.
</ResponseField>

<ResponseField name="follower_count" type="integer">
  The number of readers following this user.
</ResponseField>

<ResponseField name="story_count" type="integer">
  The number of publicly published stories by this user.
</ResponseField>

<ResponseField name="joined_at" type="string">
  The ISO 8601 timestamp at which the user joined Story.
</ResponseField>

## Get a user

Retrieve the public profile of a single user. You can look up a user by their numeric ID or by their @username.

```
GET /users/{id}
```

### Path parameters

<ParamField path="id" type="string" required>
  The user's numeric ID or their @username (e.g. `@johndoe`). When using a username, include the `@` prefix.
</ParamField>

### Example request

```bash
curl https://api.story.app/v1/users/@johndoe \
  -H "Authorization: Bearer $STORY_API_KEY"
```

### Example response

```json
{
  "data": {
    "id": "usr_789xyz",
    "username": "johndoe",
    "display_name": "John Doe",
    "bio": "Fantasy and sci-fi writer. Lover of long chapters and unreliable narrators.",
    "profile_photo_url": "https://cdn.story.app/avatars/usr_789xyz.jpg",
    "follower_count": 4821,
    "story_count": 6,
    "joined_at": "2022-08-14T10:30:00Z"
  },
  "meta": {
    "request_id": "req_usr001"
  }
}
```

## List stories by a user

Retrieve a paginated list of publicly published stories by a specific user.

```
GET /users/{id}/stories
```

### Path parameters

<ParamField path="id" type="string" required>
  The user's numeric ID or their @username (e.g. `@johndoe`).
</ParamField>

### Query parameters

<ParamField query="page" type="integer" default="1">
  The page number to retrieve.
</ParamField>

<ParamField query="per_page" type="integer" default="20">
  The number of stories to return per page. Maximum is `100`.
</ParamField>

### Example request

```bash
curl https://api.story.app/v1/users/@johndoe/stories?page=1&per_page=3 \
  -H "Authorization: Bearer $STORY_API_KEY"
```
